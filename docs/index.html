Research agent

From a website hint to a verdict

Discover

Start with the app directory and five pilot seed sets. Rank links for authentication, API references, pricing and MCP documentation.

Extract

Fetch public pages within host limits. Save source receipts, text signals and per-app checkpoints. Classify with auditable Python rules.

Reconcile

Read vendor guides and plan terms, inspect named MCP publishers, compare commercial catalog entries and flag conflicting claims.

Verify

Recheck citations, compare sampled claims against primary sources and look for specific text in a rendered browser. Preserve all scored outcomes.

Scope and limitations

READY means a scoped prototype has a documented interface and an accessible developer path. CONDITIONAL covers meaningful plan, permission, quota or deployment limits. GATED requires vendor, enterprise or partner involvement. BLOCKED requires evidence of an impractical route. UNKNOWN preserves unresolved evidence.

Access describes the initial credential route. Buildability also considers the proposed toolkit's production use. Breadth is qualitative: focused covers a single task family, moderate spans several related workflows and broad covers multiple resource families. Public API documentation can describe a commercially gated product.

The agent used local Python and public documentation. Composio's public catalog was checked for existing coverage. No authenticated Composio SDK sessions, provider account signups, live customer actions or paid inference were used. A catalog miss may reflect naming, packaging or a different upstream provider.
